Comandos esenciales para preparar y depurar conjuntos de datos

Comando Categoría Descripción Ejemplo Retorna
pd.read_csv() Importar Importa un archivo CSV (o TSV) a un DataFrame. Soporta encoding, separador, fechas y más. 
df = pd.read_csv('datos.csv', sep=',',
        encoding='utf-8',
        parse_dates=['fecha'])
 DataFrame
pd.read_excel() Importar Lee archivos .xlsx o .xls. Permite elegir la hoja y rango de celdas. 
df = pd.read_excel('reporte.xlsx',
        sheet_name='Ventas',
        header=0)
 DataFrame
pd.read_sql() Importar Ejecuta una consulta SQL sobre una conexión (SQLAlchemy, sqlite3, etc.) y devuelve el resultado. 
from sqlalchemy import create_engine
engine = create_engine('sqlite:///bd.db')
df = pd.read_sql('SELECT * FROM clientes
  WHERE activo = 1', con=engine)
 DataFrame
pd.read_sql_table() Importar Importa una tabla completa de una base de datos relacional usando SQLAlchemy. 
df = pd.read_sql_table('productos',
        con=engine,
        schema='public')
 DataFrame
pd.read_json() Importar Carga datos desde un archivo JSON o una cadena JSON. Ideal para respuestas de APIs REST. 
df = pd.read_json('datos.json',
        orient='records')
 DataFrame
pd.json_normalize() Importar Aplana un JSON anidado (respuesta de API) en un DataFrame tabular. 
import requests, pandas as pd
resp = requests.get('https://api.ejemplo.com/data')
df = pd.json_normalize(resp.json(),
        record_path='items')
 DataFrame
pd.read_html() Importar Hace web scraping de tablas HTML en una URL o cadena HTML. Devuelve una lista de DataFrames. 
tablas = pd.read_html(
  'https://ejemplo.com/estadisticas')
df = tablas[0]  # primera tabla
 list[DataFrame]
pd.read_parquet() Importar Lee archivos Parquet, formato columnar eficiente usado en Big Data y data lakes. 
df = pd.read_parquet('datos.parquet',
        columns=['id','monto','fecha'])
 DataFrame
pd.read_clipboard() Importar Importa datos tabulares copiados en el portapapeles (útil desde Excel o una web). 
# Copiar tabla en Excel, luego:
df = pd.read_clipboard(sep='\t')
 DataFrame
df.info() Explorar Muestra tipos de datos, valores no nulos y uso de memoria de cada columna. 
df.info()
 None (imprime)
df.describe() Explorar Estadísticas descriptivas: media, desv. estándar, mín./máx. y percentiles. 
df.describe(include='all')
 DataFrame
df.shape Explorar Devuelve la dimensión del DataFrame (filas, columnas). 
rows, cols = df.shape
 tuple
df.dtypes Explorar Tipo de dato de cada columna. 
df.dtypes
 Series
df.value_counts() Explorar Frecuencia de valores únicos en una columna. 
df['col'].value_counts()
 Series
df.isnull() Nulos Máscara booleana que indica dónde hay valores NaN. 
df.isnull().sum()
 DataFrame / Series
df.notnull() Nulos Inverso de isnull(): True donde el valor existe. 
df[df['col'].notnull()]
 DataFrame / Series
df.dropna() Nulos Elimina filas (o columnas) con al menos un NaN. Configurable con thresh y subset. 
df.dropna(subset=['edad','nombre'])
 DataFrame
df.fillna() Nulos Rellena NaN con un valor fijo, la media, la mediana u otro método. 
df['precio'].fillna(df['precio'].median())
 DataFrame / Series
df.interpolate() Nulos Estima NaN mediante interpolación lineal o de tiempo para series ordenadas. 
df['temp'].interpolate(method='linear')
 Series
df.duplicated() Duplicados Marca como True las filas duplicadas. Acepta subset y keep. 
df.duplicated(subset=['id']).sum()
 Series (bool)
df.drop_duplicates() Duplicados Elimina filas duplicadas, conservando la primera (o última) ocurrencia. 
df.drop_duplicates(keep='first')
 DataFrame
df.astype() Tipos Convierte el tipo de dato de una o varias columnas. 
df['precio'] = df['precio'].astype(float)
 Series / DataFrame
pd.to_numeric() Tipos Convierte a numérico; con errors='coerce' transforma errores en NaN. 
pd.to_numeric(df['col'], errors='coerce')
 Series
pd.to_datetime() Tipos Convierte cadenas o números a tipo datetime. 
df['fecha'] = pd.to_datetime(df['fecha'], format='%Y-%m-%d')
 Series (datetime)
df.convert_dtypes() Tipos Infiere y convierte automáticamente al tipo más apropiado con soporte para NA. 
df = df.convert_dtypes()
 DataFrame
str.strip() Texto Elimina espacios en blanco al inicio y al final de cadenas. 
df['nombre'] = df['nombre'].str.strip()
 Series (str)
str.lower() / upper() Texto Normaliza el texto a minúsculas o mayúsculas para evitar duplicados por caso. 
df['ciudad'] = df['ciudad'].str.lower()
 Series (str)
str.replace() Texto Sustituye patrones de texto; admite expresiones regulares. 
df['tel'] = df['tel'].str.replace(r'\D', '', regex=True)
 Series (str)
str.contains() Texto Filtra filas donde la columna contiene un patrón (regex o literal). 
df[df['email'].str.contains('@', na=False)]
 Series (bool)
str.split() Texto Divide cadenas y puede expandirlas en columnas separadas. 
df[['nombre','apellido']] = df['nombre_completo'].str.split(' ', n=1, expand=True)
 DataFrame
df.clip() Outliers Limita los valores a un rango [lower, upper] sin eliminar filas. 
df['edad'] = df['edad'].clip(lower=0, upper=120)
 Series / DataFrame
df.quantile() Outliers Calcula percentiles para definir umbrales de outliers (p.ej. método IQR). 
Q1 = df['val'].quantile(0.25)
Q3 = df['val'].quantile(0.75)
IQR = Q3 - Q1
 float / Series
df.where() Outliers Reemplaza con NaN (u otro valor) donde la condición es False. 
df['val'].where(df['val'] < 1000, other=np.nan)
 Series
df.reset_index() Índice Reinicia el índice a 0,1,2… opcionalmente moviendo el índice anterior a columna. 
df.reset_index(drop=True, inplace=True)
 DataFrame
df.set_index() Índice Establece una columna como índice del DataFrame. 
df = df.set_index('id_cliente')
 DataFrame
df.sort_values() Índice Ordena el DataFrame por una o varias columnas. 
df.sort_values('fecha', ascending=True)
 DataFrame
df.rename() Renombrar Cambia nombres de columnas o índices de forma selectiva. 
df.rename(columns={'old':'new', 'age':'edad'})
 DataFrame
df.drop() Renombrar Elimina filas o columnas por nombre. 
df.drop(columns=['col_irrelevante'])
 DataFrame
df.columns Renombrar Lista o reemplaza todos los nombres de columna en bloque. 
df.columns = df.columns.str.strip().str.lower().str.replace(' ','_')
 Index
df.melt() Renombrar Convierte columnas anchas a formato largo (unpivot). 
df.melt(id_vars=['id'], value_vars=['q1','q2'])
 DataFrame
